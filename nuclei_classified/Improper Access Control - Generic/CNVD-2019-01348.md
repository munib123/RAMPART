# Nuclei Template: Xiuno BBS CNVD-2019-01348
**Template ID:** CNVD-2019-01348
**Vulnerability Class:** Improper Access Control - Generic
**Severity:** High
**CWE:** CWE-284
**Source:** Nuclei Template (`CNVD-2019-01348.yaml`)

## Vulnerability Information & PoC

## Description
The Xiuno BBS system has a system reinstallation vulnerability. The vulnerability stems from the failure to protect or filter the installation directory after the system is installed. Attackers can directly reinstall the system through the installation page.

## Steps to reproduce / Exploit Payload
```http
GET {{BaseURL}}/install/
```

## Remediation
Upgrade to the latest version of Xiuno BBS or switch to a supported product.
