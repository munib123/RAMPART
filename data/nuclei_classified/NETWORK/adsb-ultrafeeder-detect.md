# Vulnerability: ADSB Ultrafeeder Beast Mode - Detection
**Classification:** NETWORK
**Source:** Nuclei Template (`adsb-ultrafeeder-detect.yaml`)

## Description
Detected ADS-B (Automatic Dependent Surveillance–Broadcast) ultrafeeders operating with the Beast Mode protocol on port 30005. These devices capture aircraft transponder signals using software-defined radios (SDRs) and distribute the decoded data over the internet.
