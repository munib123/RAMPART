# Nuclei Template: Ruijie Smartweb - Default Password
**Template ID:** CNVD-2020-56167
**Vulnerability Class:** Use of Default Credentials
**Severity:** Low
**Source:** Nuclei Template (`CNVD-2020-56167.yaml`)

## Vulnerability Information & PoC

## Description
Ruijie Smartweb contains a vulnerability via the default password. An attacker can successfully bypass entering required credentials, thus possibly obtain sensitive information from a database, modify data, and execute unauthorized administrative operations in the context of the affected site.
