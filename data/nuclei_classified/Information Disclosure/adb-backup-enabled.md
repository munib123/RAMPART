# Nuclei Template: ADB Backup Enabled
**Template ID:** adb-backup-enabled
**Vulnerability Class:** Information Disclosure
**Severity:** Low
**CWE:** CWE-200
**Source:** Nuclei Template (`adb-backup-enabled.yaml`)

## Vulnerability Information & PoC

## Description
ADB Backup is enabled, which allows the backup and restore of an app's private data.

## Remediation
Ensure proper access or disable completely.
