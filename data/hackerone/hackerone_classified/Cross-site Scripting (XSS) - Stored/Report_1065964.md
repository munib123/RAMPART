# HackerOne Report: Stored XSS in the banner block description
**Report ID:** 1065964
**Vulnerability Class:** Cross-site Scripting (XSS) - Stored

## Vulnerability Information & PoC
## Steps To Reproduce:

- Create a new template and add a banner block

{F1128944}

- Add a description to the banner block description: `"><img src=1 onerror=alert(document.domain)>`

- Malicious code executed
