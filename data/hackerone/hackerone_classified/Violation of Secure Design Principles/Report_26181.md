# HackerOne Report: DNS load balancing not enabled
**Report ID:** 26181
**Vulnerability Class:** Violation of Secure Design Principles

## Vulnerability Information & PoC
Hello there
I found out that there is no DNS load balancing enabled on the web application on your webserver. This allows attackers to carry out attacks against the DNS via your designated IP. You should enabled DNS load balancing
