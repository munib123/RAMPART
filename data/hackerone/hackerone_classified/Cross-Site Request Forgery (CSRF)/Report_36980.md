# HackerOne Report: Notifications can mark as read by CSRF
**Report ID:** 36980
**Vulnerability Class:** Cross-Site Request Forgery (CSRF)

## Vulnerability Information & PoC
<script src="https://twitter.com/i/notifications"></script>

If a website use this code, visitor's Twitter notifications will be marked as read.

You can easily check it locally, I'm not uploading any proof or file.
