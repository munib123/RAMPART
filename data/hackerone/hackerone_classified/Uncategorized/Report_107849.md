# HackerOne Report: [https://test1.owncloud.com/owncloud6/] Guessable password used for admin user
**Report ID:** 107849
**Vulnerability Class:** Uncategorized

## Vulnerability Information & PoC
On https://test1.owncloud.com/owncloud6/ there is easy to guess password set for admin user. 
Login with: 

admin/admin

Other instances of owncloud i was able to find on that server have different password set for admin.
