## What changed

1. **Split.** `locators.sc` → `rules/00_prelude … 90_finish.sc`, concatenated in file-name order.
   The `// @@` section contract is unchanged, plus one new non-rule section, `flow`. Rule
   families get their own files. `scan.rules_source()` / `rules_sha256()` replace the single
   path. `perItem(rule)(items)(judge)` is now the only way a rule runs. A collection that throws
   is that rule's throw, not the program's. Shared flow tables are built under `table()`: a
   table that throws is empty and named in `diag.table_errors`.
2. **Cheaper context.**
   - Each method's AST and contained calls are materialised once and filtered by `Set`. Before,
     every slot was a separate `nameExact` traversal.
   - Class bodies are walked once.
   - The route hops use one `callIn` per method. The P7 code ran it twice per method and
     rebuilt `direct ++ hop1` for every method of hop 2.
3. **Eight rules** that need value flow, which the four per-method rules never had:

| rule | CWE | what the graph adds over a pattern |
|---|---|---|
| `joern-ignored-auth-result` | 287 | the check's value is never used (AST parent is a statement block, after unwrapping pysrc2cpg's expression blocks); project checks recognised by None-or-value returns |
| `joern-hardcoded-credential-compare` | 798 | the compared value resolves to a string literal through `config.NAME` in another module; the value is never echoed |
| `joern-ssrf-request-url` | 918 | URL argument → local def-use → parameter → the caller's argument is request input |
| `joern-path-traversal` | 22 | same flow into `open` / `send_file` / `os.remove`; a sanitiser on the path suppresses |
| `joern-cors-wildcard` | 942 | header value resolves to `"*"`, written unconditionally |
| `joern-cleartext-transport` | 319 | HTTP client URL resolves to a non-loopback `http://` constant |
| `joern-xxe-parser` | 611 | parser keyword resolves to an unsafe setting |
| `joern-debug-exposed` | 489 | `run(debug=…)` resolves to `True` |

The four config-flow rules report the line that **defines** the value, e.g. `config.py:29`, and
the message names the sink, e.g. `add_cors() at app.py:19`. One finding per definition.

The first version of `joern-cors-wildcard` fired twice inside starlette's `CORSMiddleware`. Both
writes are `"*"` under `if allow_all_origins:`, i.e. a configured policy. The rule now requires

probe-flow, and `add_cors_public` (conditional) stays quiet by design.

findings. Warm per-scan time is 4.8–5.7 s.
